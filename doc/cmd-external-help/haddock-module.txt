Build the Haddock page of one module of a local package.

Usage: cabal haddock-module [FLAGS] [PACKAGE:]MODULE
   or: cabal haddock-module [FLAGS] FILE

Renders the Haddock page of MODULE on its own, against the library that cabal has already built, which is much faster than documenting the whole component as 'cabal haddock MODULE' does. The library is built first unless --no-build is given. MODULE may be any module of a local package's main library, hidden ones included; name the package when more than one has the module, or give the path of the module's source file instead.

The page goes under <builddir>/haddock-module/<package>/ by default. Links to other modules go to the documentation cabal has generated for them, if any, so they resolve once 'cabal haddock' has run for the package and its dependencies.

This is an external command: cabal runs the cabal-haddock-module executable that cabal-install installs next to cabal. Global flags are not passed to it; give --builddir and --project-file after the command name. They and the other options here go to the build it runs; the rest of the build's configuration comes from the project files.

Flags for haddock-module:
 -h, --help                   # Show this help text
 -v[n], --verbose[=n]         # Control verbosity (n is 0--3, default
                                verbosity level is 1)
 --builddir=DIR               # The directory where Cabal puts generated build
                                files (default dist)
 --keep-temp-files            # Keep temporary files.
 -w PATH or -wPATH, --with-compiler=PATH
                              # Give the path to a particular compiler
 --with-hc-pkg=PATH           # Give the path to the package tool
 --with-PROG=PATH             # Give the path to PROG
 --project-dir=DIR            # Set the path of the project directory
 --project-file=FILE          # Set the path of the cabal.project file
                                (relative to the project directory when
                                relative)
 --no-build                   # Do not build the library first; document the
                                module as last built.
 --output-dir=DIR             # Directory to put the page in (default:
                                <builddir>/haddock-module/<package>).

Examples:
  cabal haddock-module Foo.Bar
    Document module Foo.Bar of the local package that has it.
  cabal haddock-module --no-build pkg:Foo.Bar
    Document module Foo.Bar of package pkg as last built.
  cabal haddock-module pkg/src/Foo/Bar.hs
    Document the module in that source file.
