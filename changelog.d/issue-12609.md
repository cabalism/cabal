---
synopsis: "Fix `cabal init` failing with too many open source files"
packages: [cabal-install]
prs: 0
issues: 12609
---

When looking for the modules of a package with more source files than the limit
on open files allows, `cabal init` failed with `openFile: resource exhausted
(Too many open files)`. It now closes each file before opening the next.

This was fixed before, in `cabal-install-3.6`, and came back with the rewrite of
`cabal init` in `cabal-install-3.8`.
