{{FG_GREEN}}Core switch{{RST}}: {{B}}{{FG_LIME}}--[enable|disable]-documentation{{RST}}
{{DIM}}Turn docs on/off globally for the build plan. Useful for fast local builds vs CI/doc jobs.{{RST}}

{{DIM}}Use a central index template when you want multiple package docs to appear under one umbrella page.{{RST}}

{{FG_VIOLET}}Generators{{RST}}
  {{FG_PINK}}•{{RST}} --haddock-hoogle            {{DIM}}→ build a Hoogle database for symbol/name search across docs{{RST}}
  {{FG_PINK}}•{{RST}} --haddock-html              {{DIM}}→ produce HTML docs (default style output){{RST}}
  {{FG_PINK}}•{{RST}} --haddock-html-location=URL {{DIM}}→ link dependencies to already-hosted docs{{RST}}
  {{FG_PINK}}•{{RST}} --haddock-for-hackage       {{DIM}}→ convenience bundle for Hackage-friendly docs{{RST}}
{{DIM}}If you are publishing docs remotely, these four options usually form your baseline toolkit.{{RST}}

{{FG_ORANGE}}Target matrix{{RST}}
  {{FG_GOLD}}exe{{RST}}: --haddock-executables     {{DIM}}document executable entrypoints / exposed modules{{RST}}
  {{FG_GOLD}}test{{RST}}: --haddock-tests          {{DIM}}document test-suite code for internal team discoverability{{RST}}
  {{FG_GOLD}}bench{{RST}}: --haddock-benchmarks    {{DIM}}document benchmark internals and harness assumptions{{RST}}
  {{FG_GOLD}}all{{RST}}: --haddock-all             {{DIM}}run haddock for every target category in this package{{RST}}
  {{FG_GOLD}}internal{{RST}}: --haddock-internal   {{DIM}}include hidden/internal modules and private symbols{{RST}}
{{DIM}}Tip: prefer explicit subsets locally; reserve --haddock-all for release/CI consistency checks.{{RST}}
{{HR}}
{{FG_GREEN}}Styling + source map{{RST}}
  --haddock-css=PATH
  {{DIM}}Apply a custom CSS theme to generated docs. Great for internal branding/readability tweaks.{{RST}}
  --haddock-hyperlink-source, --haddock-hyperlink-sources, --haddock-hyperlinked-source
  {{DIM}}Enable source-code hyperlinks from API declarations to implementation lines.{{RST}}
  --haddock-quickjump
  {{DIM}}Generate interactive jump index for instant navigation in large modules/packages.{{RST}}
  --haddock-hscolour-css=PATH
  {{DIM}}Style syntax-highlighted source pages produced via HsColour integration.{{RST}}
{{HR}}
{{FG_VIOLET}}Remote wiring{{RST}}
  --haddock-contents-location=URL
  {{DIM}}Bake an external contents page URL into docs (handy when docs are split across hosts).{{RST}}
  --haddock-base-url=URL
  {{DIM}}Set base URL for static assets so pages resolve correctly behind proxies/CDNs/subpaths.{{RST}}
  --haddock-use-unicode
  {{DIM}}Pass unicode rendering through to Haddock for nicer symbols/operators in generated pages.{{RST}}
